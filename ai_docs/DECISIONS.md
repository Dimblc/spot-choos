# DECISIONS — Spot & Choo's

## 2026-06-24
### Обновление AI-документации
- **Решение:** Привести `AI_INDEX.md`, `PROJECT_OVERVIEW.md`, `ARCHITECTURE.md`, `FILE_MAP.md`, `FUNCTIONS_MAP.md`, `OPEN_TASKS.md`, `CODING_RULES.md`, `DEPLOYMENT.md` и `API.md` в соответствие с актуальным состоянием проекта.
- **Причина:** Документация содержала устаревшие данные (отсутствовала `/gallery`, устаревшая информация о шрифтах, неотмеченные выполненные задачи).
- **Автор:** AI.

### Форма обратной связи через Google Forms
- **Решение:** Использовать Google Forms для обработки сообщений с форм на главной (`Contact.tsx`) и на `/contact/page.tsx`. Конфигурация (action, entry IDs) вынесена в `src/lib/data.ts` в объект `contactForm`.
- **Альтернатива:** Собственный backend endpoint `/api/contact` с email-рассылкой.
- **Причина:** Быстрый способ получать сообщения без развёртывания backend-сервиса и без хранения секретов (SMTP, API-ключи).
- **Автор:** AI.

### Шрифт для кириллицы: PoppingCute
- **Решение:** Использовать локальный шрифт `PoppingCute.ttf` (`public/fonts/PoppingCute.ttf`) в качестве основного для кириллицы, подключённый через `next/font/local`.
- **Альтернатива:** `Comic CAT`, `Lobster`, другие rounded/comic шрифты.
- **Причина:** `PoppingCute` лучше совпадает с визуальным стилем бренда и уже используется в текущей версии `layout.tsx`.
- **Автор:** AI.

## 2026-06-23
### Выбор стека и архитектуры
- **Решение:** Использовать Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + GSAP + Lenis.
- **Альтернативы:** Чистый HTML/CSS, другие фреймворки (Astro, Nuxt).
- **Причина:** Пользователь хочет сайт, похожий на CRAV Burgers, который использует Next.js с богатыми анимациями. App Router + GSAP + Lenis позволяют повторить эффекты (pop-up текста, jelly-волны, плавный скролл, стикеры).
- **Автор:** AI.

### Структура компонентов
- **Решение:** Разделить компоненты на `ui/`, `layout/`, `sections/`, `animations/`.
- **Причина:** Чёткое разделение ответственности; анимации изолированы в клиентских компонентах, секции легко заменять.
- **Автор:** AI.

### Создание AI-памяти
- **Решение:** В проекте внедрена Markdown-based AI memory.
- **Файлы:** `AGENTS.md`, `AI_INDEX.md`, `ai_docs/*.md`.
- **Причина:** Упрощение работы будущих AI-агентов с проектом.
- **Автор:** AI.

### Запуск dev-сервера
- **Решение:** Запускать `next` напрямую через `node ./node_modules/next/dist/bin/next dev`.
- **Альтернатива:** Переименовать папку без апострофа и использовать `npm run dev`.
- **Причина:** Апостроф в `Spot & Choo's` ломает npm-скрипты (путь обрезается).
- **Автор:** AI.
