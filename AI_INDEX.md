# AI_INDEX — навигация по проекту Spot & Choo's

## Статус
Проект активно развивается. Базовый лендинг, вспомогательные страницы, анимации, реальные данные и форма обратной связи уже на месте. Остались задачи по адаптиву, SEO и внешним изображениям.

## Первый шаг для нового AI
1. Прочитать этот `AI_INDEX.md`.
2. Прочитать `ai_docs/PROJECT_OVERVIEW.md` и `ai_docs/CODING_RULES.md`.
3. Открыть `ai_docs/OPEN_TASKS.md` — там актуальные задачи.
4. Только после этого анализировать код.
